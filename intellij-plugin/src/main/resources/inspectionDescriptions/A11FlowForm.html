Reports forms the A11 Flow language does not have, or does not have in that position: an unknown pipeline stage or built-in function, a stage without the argument it takes, a port type that is neither built in nor written as a registry tag, an unknown status code after fail, stream or required written in front of a port's type, node without its parentheses, headers without the forward that owns it, a port or a flow declared twice, and a count that is not a number of anything (parallel 0, skip -1).

These are the problems the compiler refuses to read, so a flow reported here does not run. A flow written inside a string literal is only reported for a grammatical problem when the string holds a whole flow declaration -- a fragment is a few statements out of one, and half a statement is not a mistake.
