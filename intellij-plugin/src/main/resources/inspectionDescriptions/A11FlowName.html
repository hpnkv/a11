Reports names a flow cannot resolve, and names used as something they are not.

A flow reads in order, so a name means nothing above the statement that binds it; this reports a name nothing has bound yet, a name already taken in the same scope, a node map used before nodes declares it, and it outside the where, map or group stage whose value it names.

It also reports names used in the wrong role: a call where one of its ports was meant (x rather than x.output), a write to an in port or to a call's output, a read of an out port, a port a called sibling flow does not declare, and a status asked of something that has none.
