# A11 for TypeScript

A11 is a streaming action runtime for AI agents, model serving, and multimodal
APIs. This package provides the TypeScript action, node, session, transport,
and LLM data interfaces for Node.js and browsers.

- Read text, reasoning, progress, tool activity, and durable state from named
  streams.
- Keep the same action contract when a handler moves between a page, local
  process, and remote service.
- Connect through WebSocket, HTTP SSE, WebRTC, or an in-process stream.

```sh
npm install @curiositystack/a11
```

Start with the [browser client
guide](https://docs.a11.to/guides/browser-clients.html) or open the
[TypeScript API reference](https://docs.a11.to/typescript.html).
